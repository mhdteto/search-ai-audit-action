# Changelog

## 1.0.0 — 2026-11-04

First stable reusable Action release.

- Linux composite Action using Python 3.12 and the unmodified v1.0.0 bounded public-page checker.
- Explicit URL, optional synthetic fixture and workspace-relative report destination inputs.
- JSON, standalone HTML, transport outputs and a GitHub job summary.
- Literal environment-variable inputs; workspace traversal/symlink and fixture-collision checks.
- Eight wrapper tests, 21 upstream tests and an actual composite-action fixture workflow.
- Original social preview, usage examples and source/license provenance.

Successful execution means a report was produced. It does not establish indexing, ranking, AI retrieval or citations. The caller controls artifact uploads and retention. No executable code changed during release preparation.
